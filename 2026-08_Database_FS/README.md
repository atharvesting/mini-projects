# Database FS

Database from Scratch: Following the popular ["Let's Build a Simple Database"](https://cstack.github.io/db_tutorial/)
tutorial, with the twist that I will translate its C code to C++ to leverage modern features. I like these sort of 
exercises as they force me to contemplate the purpose of C++ as a language and explore its feature set.

The goal of this project is to understand database internals and be able to implement more sophisticated data systems that 
support ingestion, storage and retrieval. I may even consider expanding on this project to support desired features. Further
details to be finalized soon.
